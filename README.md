# ChatRelay

Move your AI coding chat history (Claude Code, Codex) between computers, and from one AI tool
to another. (Formerly "Claude Sync".)

**[Download the latest version](https://github.com/Abh1shxkk/claude-sync-releases/releases/latest)**

- **Windows**: download `ChatRelay_<version>_x64-setup.exe` and run it. Install it once —
  the app tells you when a new version is out and updates itself with one click.
- **Android**: download the `.apk` file on your phone and open it.

This repository only holds release files.
